#### Installation (seting up requirements)

Change directory to the function-calling-tutorial folder
```bash
cd function-calling-tutorial
```

Give execute permissions to the install_req.bash file
```bash
chmod +x install_req.bash
```

Run the script
```bash
./install_req.bash
```

Then select the recently created venv as the jupyter enviroment, voilá!

create a .env file in the function-calling-tutorial folder and add the following line:
```bash
OPENAI_API_KEY="{the api key I sent you}"
```
